# TheMrRaGe.github.io

Portfolio site for Heath Dale — plain HTML/CSS/JS, no build step.

- `index.html` — home: intro, selected work, about
- `gallery.html` — every project, filterable, with a detail view (`gallery.html#moodscape` deep-links)
- `assets/projects.js` — **all project content lives here**; edit it to add or change projects
- `assets/art.js` — generative thumbnails for projects without screenshots
- `img/` — real screenshots (set `image: "img/…"` on a project to use one)

Deployed with GitHub Pages from the `main` branch root.
